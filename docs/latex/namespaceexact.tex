\doxysubsection{Detailed Description}
Contains mathematical programming models for exact optimization. 

Utilizes the IBM ILOG CPLEX optimizer to solve the network resource allocation problem to optimality or within a specified time limit, providing an exact baseline by maximizing avoided non-\/service penalties.
