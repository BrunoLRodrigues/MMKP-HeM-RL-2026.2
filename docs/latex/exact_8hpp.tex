\doxysubsection{Detailed Description}
Exact Integer Linear Programming (ILP) formulations using IBM ILOG CPLEX. 

Provides the mathematical optimization model and solver configuration to solve the Multiple Multidimensional Knapsack Problem (MMKP) for Io\+T-\/\+EC-\/\+CC resource allocation.
