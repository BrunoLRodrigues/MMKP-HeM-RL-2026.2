\doxysubsubsection{Detailed Description}
Core data structures, synthetic dataset generators, metric trackers, and console/file display routines. 

Defines the domain entities ({\ttfamily Device}, {\ttfamily Server}, {\ttfamily Supply}), dataset loading/generation utilities, polymorphic metric collection classes ({\ttfamily Metrics}, {\ttfamily Exact\+Metrics}, {\ttfamily Heuristic\+Metrics}, {\ttfamily Meta\+Heuristic\+Metrics}), and ASCII table visualization functions for the MMKP Io\+T-\/\+EC-\/\+CC simulator.
