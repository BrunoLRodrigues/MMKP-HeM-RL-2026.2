Simulador em C++17 para resolução do {\bfseries{Problema das Múltiplas Mochilas Multidimensionais (MMKP)}} aplicado à alocação de recursos em infraestruturas de {\bfseries{Internet das Coisas (IoT)}}, {\bfseries{Computação de Borda (EC)}} e {\bfseries{Computação em Nuvem (CC)}}. O simulador avalia métodos Exatos (ILP via IBM ILOG CPLEX), Heurísticas Construtivas e Meta-\/heurísticas ({\itshape Simulated Annealing}).

Os parâmetros do experimento podem ser ajustados diretamente em {\ttfamily \doxylink{main_8cpp}{src/main.\+cpp}}\+:


\begin{DoxyItemize}
\item {\ttfamily SERVICES = 100}\+: Quantidade de perfis de serviços.
\item {\ttfamily DEVICES\+\_\+\+START = 10000}, {\ttfamily DEVICES\+\_\+\+STEP = 1000}, {\ttfamily DEVICES\+\_\+\+END = 20000}\+: Escala de dispositivos IoT.
\item {\ttfamily EC\+\_\+\+LENGTH = 499}, {\ttfamily CC\+\_\+\+LENGTH = 1}\+: Quantidade de servidores de Borda (EC) e Nuvem (CC).
\item {\ttfamily MAX\+\_\+\+RUNS = 50}\+: Número de execuções independentes por instância.
\item {\ttfamily CPLEX\+\_\+\+TIME\+\_\+\+LIMIT = 3600}\+: Tempo limite do CPLEX em segundos (1 hora).
\item {\ttfamily TEMPERATURE = 50.\+0}, {\ttfamily ALPHA = 0.\+9999}\+: Parâmetros de resfriamento do {\itshape Simulated Annealing}.
