\doxysubsubsection{Detailed Description}
Constructive heuristic algorithms for fast MMKP resource allocation. 

Implements deterministic cost-\/benefit greedy allocation ({\ttfamily greedy\+\_\+cost\+\_\+benefit}) as well as stochastic single-\/stage ({\ttfamily greedy\+\_\+random}) and two-\/stage Edge-\/first ({\ttfamily greedy\+\_\+random\+\_\+fallback}) constructive heuristics.
