A C++17 simulator for solving the {\bfseries{Multiple Multidimensional Knapsack Problem (MMKP)}} applied to resource allocation across {\bfseries{Internet of Things (IoT)}}, {\bfseries{Edge Computing (EC)}}, and {\bfseries{Cloud Computing (CC)}} infrastructures. The simulator evaluates Exact (ILP via IBM ILOG CPLEX), Constructive Heuristic, and Meta-\/heuristic (Simulated Annealing) paradigms.

\begin{DoxyItemize}
\item {\ttfamily SERVICES = 100}\+: Number of service profiles.
\item {\ttfamily DEVICES\+\_\+\+START = 10000}, {\ttfamily DEVICES\+\_\+\+STEP = 1000}, {\ttfamily DEVICES\+\_\+\+END = 20000}\+: Device scaling range.
\item {\ttfamily EC\+\_\+\+LENGTH = 499}, {\ttfamily CC\+\_\+\+LENGTH = 1}\+: Number of Edge and Cloud servers.
\item {\ttfamily MAX\+\_\+\+RUNS = 50}\+: Number of independent runs per instance.
\item {\ttfamily CPLEX\+\_\+\+TIME\+\_\+\+LIMIT = 3600}\+: Maximum solver runtime in seconds (1 hour).
\item {\ttfamily TEMPERATURE = 50.\+0}, {\ttfamily ALPHA = 0.\+9999}\+: Simulated Annealing cooling schedule.
