\doxysubsection{Detailed Description}
Meta-\/heuristic optimization algorithms and neighborhood operators for MMKP. 

Implements Simulated Annealing (SA) with incremental delta evaluation and shift/insert/swap neighborhood moves to refine initial constructive heuristic solutions.
