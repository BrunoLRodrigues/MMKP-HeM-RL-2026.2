\doxysubsection{Detailed Description}
Encapsulates meta-\/heuristic algorithms for network resource allocation. 

Provides trajectory-\/based optimization techniques, specifically Simulated Annealing, to iteratively improve initial heuristic solutions by exploring shift, insertion, and 1-\/for-\/1 swap neighborhood structures.
