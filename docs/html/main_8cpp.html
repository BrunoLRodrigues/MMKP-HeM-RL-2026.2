Detailed Description

Entry point and benchmark runner for the MMKP IoT-EC-CC resource allocation simulator.

Defines the experimental parameters (scaling of IoT devices, server counts, CPLEX time limit, and Simulated Annealing cooling schedule) and orchestrates the execution across Exact, Heuristic, and Meta-heuristic paradigms.

void run_simulation ( const metrics::Result &  base,
int  option,
int  run_id 
)

Executes a specific algorithm configuration for the network resource allocation simulation.

Instantiates the appropriate metrics tracker based on the selected option, dispatches the simulation state to the corresponding solver paradigm (Exact, Heuristic, or Meta-heuristic), computes final utilization/cost metrics, and saves the results to disk.

Parameters
baseThe initial system state containing untouched devices and servers.
optionThe identifier for the algorithm combination to execute:
  • 0: Exact CPLEX solver (solver_maximum_cost)
  • -1: Constructive heuristic (greedy_cost_benefit)
  • -2: Constructive heuristic (greedy_random)
  • -3: Constructive heuristic (greedy_random_fallback)
  • 1: Simulated Annealing + greedy_cost_benefit
  • 2: Simulated Annealing + greedy_random
  • 3: Simulated Annealing + greedy_random_fallback
run_idThe current execution run number (1-indexed).
