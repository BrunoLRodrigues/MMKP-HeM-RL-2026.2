Generates or loads device request data representing IoT network demands.

Uniformly samples service requirement profiles from the services dataset and assigns them to each device instance in data/devices/Devices_<length>.txt. If the file already exists, synchronizes each device's penalty cost (COST) with its corresponding service template.

Parameters
lengthThe total number of devices to generate.
num_servicesThe number of underlying service templates to sample from.
fixed_penaltyWhether the penalty (cost) of each device is fixed (1.0) or variable.
Returns
A 2D string vector representing the devices dataset.

Generates or loads network service requirement templates.

Creates random service profiles with varying task counts, memory, storage, and processing demands, persisting them to data/Services.txt. If the file already exists, reloads the profiles and updates their penalty costs (COST) according to fixed_penalty.

Parameters
num_servicesThe total number of distinct service profiles to generate.
fixed_penaltyIf true, assigns a unit penalty cost (1.0); if false, generates task-proportional random penalty costs.
Returns
A 2D string vector containing the generated or updated services dataset.
