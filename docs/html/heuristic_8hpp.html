Detailed Description

Constructive heuristic algorithms for fast MMKP resource allocation.

Implements deterministic cost-benefit greedy allocation (greedy_cost_benefit) as well as stochastic single-stage (greedy_random) and two-stage Edge-first (greedy_random_fallback) constructive heuristics.
