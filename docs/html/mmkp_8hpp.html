Detailed Description

Core data structures, synthetic dataset generators, metric trackers, and console/file display routines.

Defines the domain entities (Device, Server, Supply), dataset loading/generation utilities, polymorphic metric collection classes (Metrics, ExactMetrics, HeuristicMetrics, MetaHeuristicMetrics), and ASCII table visualization functions for the MMKP IoT-EC-CC simulator.
