Executes a Global Greedy Resource Allocation based on surrogate pseudo-utility.

Normalizes device resource demands against total system capacity to compute a multidimensional cost-benefit pseudo-utility and sorts candidates once globally. Allocates devices greedily per server using prefix-skipping and minimum-demand early termination.

Parameters
stateThe unified simulation result state containing devices, servers, and metrics.

Executes a fast random baseline resource allocation.

Iterates through all devices and attempts to assign each one to a single uniformly selected server. If the selected server lacks capacity, the device remains unserved. Metric calculation is deferred.

Executes a two-stage random fallback resource allocation.

Attempts to assign each device to a randomly selected Edge (EC) server first. If the selected Edge server lacks capacity, falls back to a randomly selected Cloud (CC) server.
